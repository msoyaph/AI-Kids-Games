# Example briefs

Every game in this repo was built with [Claude Code](https://claude.com/claude-code) from a
written brief. These are the original briefs, so you can see what a good one looks like and
borrow its structure for your own game.

## What they have in common

- **A clear promise:** the genre, the ages, the length of play and what makes it fun.
- **Originality as a hard rule:** inspired by a genre, never copying another game's names,
  characters, layouts, music or art. Everything is invented and generated in code.
- **The game contract:** one self-contained HTML file, no network requests, a storage prefix,
  safe storage with save versions, and an iframe-safe build.
- **Kid-safety and accessibility:** age-appropriate content, no ads, purchases or chat, readable
  text, big touch targets, reduced motion and controls for every device.
- **A way of working:** plan first, build in phases, run the game and the tests after each phase,
  commit, and keep a `CLAUDE.md` with notes, commands and status.
- **A definition of done:** tests that must pass, a size budget and a final report.

The briefs are copied as written, except that other companies' game titles are replaced with a
genre description in [brackets].
